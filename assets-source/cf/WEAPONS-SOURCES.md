## 集成处理

- GoldSrc v10 模型转换成离线网格、索引贴图和骨骼动画；`weapons.json` 记录每把新增武器的手部部件、动作别名和声音事件时间。
- 新武器保留原生持枪和装填骨骼。Vol.2 / Vol.3 的手臂按所选角色使用奥摩袖装或既有 M4 皮肤贴图的裸臂区域，避免将来源包的纹身套到所有角色。
- AWM 的原序列名仅含控制字符，按文件顺序明确映射为待机、三个射击、换弹、切出；本项目使用首个射击。AWM 使用翡翠皮肤，MP5 使用消音型，并在仓库名称中明示。
- AWM 的附加发光及环境反射重复层暂不导出，保留基础翡翠贴图和完整枪体。仓库静态枪体剔除原模型藏在镜头后的备用弹匣和枪口效果面片。
- 仓库和第三人称新增枪体从待机第一人称模型剔除手臂后烘焙；原 W 文件一并留存。手斧、工兵铲修正左右镜像。仓库按武器实际尺寸适配展示比例。
- 原有 AK/M4 手部几何与动作保留，女性 AK 左前臂加厚仍有效。

## 音频映射

- 有完整事件的武器直接使用原动作记录的声音，按本项目换弹/切枪时长同比例调度；暂停、切枪、阵亡和回合结束取消待播武器声音。
- 沙漠之鹰包没有 WAV，使用 Vol.2 中双持沙鹰的单发采样、拔枪和弹匣采样适配。
- SCAR-Light 包缺少自身引用的部分文件：开火沿用已接入 M4 的非消音采样，装填与切出使用 Vol.2 的 Galil 机械采样。这不是已核实的 SCAR 原声。
- 原 AK 使用 Vol.2 的 `G_RELOAD_AK47.WAV` 作拔枪反馈；M4 使用同包 MP5 的机械采样作拔枪反馈。匕首使用同包刀具切出和挥动声。
- 手斧与工兵铲使用各自包内 `knife_deploy1.WAV` 与 `knife_slash1.WAV`；不会发出枪声或生成子弹曳光。
- 音频原样保留，浏览器使用 Web Audio 解码；具体文件 SHA-256 与归档 MD5 核验见 `weapon-provenance.json`。
