# 旧战线 · Retro Front

一个受早期军事 FPS 氛围启发的 **iOS 横屏 FPS 游戏原型**。已有可运行的大厅、仓库、单机爆破和房间联机。仓库有 14 件可装备武器，其中 13 件使用社区移植模型，战术匕首使用本项目细化模型；当前地图导入 dustsanzo 制作的完整 CF DUST2 社区 GoldSrc 移植包，保留原建筑、44 张贴图、烘焙光照及实际高差。已接入枪械采样音效、旧版大厅循环音乐和男女死亡语音。资源来源见 `assets-source/cf/SOURCES.md`，地图详见 [沙漠灰说明](DESERT-MAP.md)。

当前是可继续开发的首版，不是 CF 官方客户端、私服后端或完整复刻。角色动画、枪械细节、地图美术和枪感仍需继续打磨。

- 电脑独立分路进攻、分散守点、感知敌情后支援、安放和拆除；不再持续跟随玩家，提供简单、标准、困难三档。

- 11 把枪使用实际模型枪口的短促火焰与移动短曳光；近墙和近处命中时截断或抑制轨迹，避免从眼睛发出整条亮线或反向穿过枪口。7 件主武器在大厅、仓库和机器人身上按实际双掌与握柄、护木接触点配准，见 [射击效果与握持说明](SHOT-EFFECTS.md)。
- 角色受击喷溅：有效枪械或近战伤害在实际命中位置播放约 0.53 秒的血液动画，支持机器人互相攻击和致命伤；存活友军不受伤。玩家也可射击或近战命中倒地遗体，包括友军遗体：喷溅位置取当前死亡动作或倒地姿态的实际蒙皮表面，墙体和射程正常限制。采用 para 的 CC0 原图集并离线内置，见 [受击效果说明](BLOOD-EFFECTS.md)。
- 战斗 HUD：圆形战术雷达按实际地图绘制浅色通道、建筑、A/B 点与朝向箭头；枪弹、瞄准镜、弹匣、切枪和跳跃使用随包内置的原创矢量图标，近战时切换为挥砍图标。默认开火键 64×64，其余战斗按钮 44×44，支持移动、开镜、开火和跳跃同时操作。
- 玩家跳跃：起跳、重力下落、落地、碰顶及箱顶站立；在回合结束后的 3 秒也可跳跃。跳跃键可单独调整位置、大小和透明度。
- 自定义按键：对局右上齿轮、大厅设置和暂停菜单均可进入；支持拖动位置、单键大小及透明度、保存、取消和恢复默认。配置随本机档案保存，单机编辑期间暂停战局，联机只停止本人的操作。
- 死亡后切换跟随队友 / 自由视角，支持移动、转向、升降；下一回合自动还原。回合胜负确定后的 3 秒可继续走动和转向，最终回合也在这 3 秒结束后结算。
- 按旧版端游实战截图调整雷达、窄比分条、左下 HP 与右下 AMMO 布局；手机按钮采用轻量白色线框，参考及验证见 [HUD 更新说明](HUD-NOTES.md)。第一人称持枪组降低并补偿枪口朝向，减少女角色手肘及近身端露出，斧铲另作取景调整。
- 多指触控：摇杆、转向和开火分别管理手指，支持移动、开镜、开火与跳跃并行；开火按钮可拖动瞄准，松开其中一个触点保留其余操作。单机后台自动暂停，联机后台停止输入、对局继续。
- iPhone / iPad 原生安装工程、全离线资源和 GitHub Actions 打包流程。

不含账号服务器、商城、英雄级武器、蹲伏或投掷物。角色移动和枪械射击、换弹使用移植包骨骼动作，未承诺与 CF 原版动作一致。

## 角色与队伍优化

- 双方各 5 人：玩家 + 4 名队友，对抗 5 名敌人；蓝色头顶标记及雷达点区分队友，HUD 显示双方存活人数。
- AI 可以攻击对方电脑；不攻击同阵营玩家，友军挡在射线上时停止开火。玩家射线被队友阻挡，但不伤害队友。击杀统计仅计算玩家实际击杀。
- 进攻队友按自己的路线推进并占点；玩家阵亡后由存活队友接手安放，携带者更换时清空安放进度；防守队友可拆除。
- 玩家阵亡但队友存活时继续回合，先播放死亡镜头，随后观战存活队友。队友全部阵亡且未安放才按消灭规则判负。
- 死亡动画播放一次后保持最终姿态；遗体保留到回合结束，新回合清理死亡/观战状态，恢复全部 10 人。
- 玩家在存活且回合进行中可击中遗体并重复触发喷溅；只检测实际角色身体，排除遗体上的枪械和队伍标记。遗体反馈不扣血、不追加击杀、连杀或比分，也不缩短原有伤害弹道；人机继续以存活敌人为攻击目标。
- 此前浏览器验证覆盖死亡动画保持、遗体可见、自动观战、新回合复位和队友标记；地图与跳跃阶段另检查了同时移动、开镜、开火与跳跃，以及跳跃键自定义保存。本次增加实际倒地表面与遗体喷溅检查。

## 现在试玩

已附上构建好的离线资源。电脑浏览器可直接打开：

`ios/RetroFront/Game/index.html`

也可在安装 Node.js 22 后，于项目根目录运行：

```sh
npm ci
npm test
npm run build
npm start
```

随后打开 `http://127.0.0.1:4173`。本地预览服务仅监听当前电脑。

电脑：WASD 移动，Space 跳跃，点击空白场景锁定鼠标，左键开火，右键瞄准，R 换弹，1 / 2 / 3 切换当前主武器 / 副武器 / 近战武器，长按 E 安放或拆除，Esc 暂停。半自动武器每次射击需要新的点击。瞄准按钮也可直接点击。

手机：横屏使用；左摇杆移动，右侧空白区域滑动转向，右侧按钮控制开火、瞄准、换弹、切枪和跳跃；进入对应区域后长按安放/拆除按钮。触发系统切后台时战局会暂停。角色仅改变展示外观，属性一致。

## GitHub 云编译 IPA

下述是工程已有的云编译方式，本轮没有上传或启动构建。**公开仓库和公开衍生安装包发布前，需先取得地图作者许可，并确认角色、枪械及音效等资源的分发权利。** 当前 CF DUST2 页面声明 CC BY-NC-ND 4.0，发布转换后的游戏资源不能按 CC0 处理，详见 [地图许可记录](assets-source/maps/desert-full/LICENSE-NOTICE.md)。

确认可分发后，上传本文件所在目录中的内容到仓库根目录，保留隐藏目录 `.github`。不要把 `node_modules` 上传。`package.json` 与 `.github` 应直接位于仓库根目录。

1. 创建一个 GitHub 仓库，把本项目上传/推送到 `main` 或 `master`。
2. 打开 **Actions → Build iOS IPA → Run workflow**。
3. 首次保持 `signed` 关闭。默认 Bundle ID 为 `com.example.retrofront`。
4. 等待运行完成，在这次运行底部 **Artifacts** 下载 `RetroFront-iOS-运行编号`。
5. 解压可得到 `RetroFront-unsigned.ipa`。

自动流程在 macOS 上运行单元测试、打包全部网页资源、构建 iOS 模拟器版本检查 Swift，再归档 arm64 真机版本。默认不会发布到 App Store，也不会创建公开 Release。

**未签名 IPA 不能直接安装到普通 iPhone。** 它是供后续签名的完整包。有效证书、描述文件和设备授权决定能否安装；不是把文件扩展名改成 IPA 就可以绕过签名。

### 直接生成已签名 IPA（可选）

准备 Apple Development 或 Apple Distribution 的 **P12 文件（含私钥）**，以及匹配 Bundle ID、证书和目标设备的 Development / Ad Hoc 描述文件。本流程不接受 App Store 或企业分发描述文件。

在仓库 **Settings → Secrets and variables → Actions** 添加：

| Secret | 内容 |
| --- | --- |
| `IOS_CERTIFICATE_P12_BASE64` | P12 文件的 Base64 文本 |
| `IOS_CERTIFICATE_PASSWORD` | 导出 P12 时设置的密码 |
| `IOS_PROFILE_BASE64` | `.mobileprovision` 文件的 Base64 文本 |

用 Windows PowerShell 转换文件时，可将输出复制到相应 Secret；不要把它们写进仓库：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes('C:\path\certificate.p12')) | Set-Clipboard
[Convert]::ToBase64String([IO.File]::ReadAllBytes('C:\path\profile.mobileprovision')) | Set-Clipboard
```

手动运行 workflow，勾选 `signed`，填写与描述文件对应的 `bundle_id`。流程会检查描述文件有效期、Bundle ID 和设备分发类型，导出签名版本。导出的 IPA 可按 Apple 的设备安装流程安装；开发调试安装可能要求开启“开发者模式”。证书过期或未包含目标设备都会导致安装失败。

### 在 Mac / Xcode 本地运行

打开 `ios/RetroFront.xcodeproj`，选择 `RetroFront` Scheme。在 Signing & Capabilities 中设置自己的 Team 与 Bundle Identifier，连接 iPhone 后 Run。最低部署版本 iOS 15；需要支持 WebGL 2 的设备。Xcode 工程使用 UIKit + WKWebView，3D 渲染由随包内置的 Three.js 提供，运行不依赖 CDN 或网络。

## 多指操作修复

开镜、换弹和切枪改为按下时触发，可在左手持续操作摇杆时由第二根手指独立操作，并避免一次触摸重复切换。已通过模拟第二触点和移动/瞄准/射击组合的自动化回归检查，仍需在目标 iPhone 上复测。源码及随包离线资源已同步更新；旧的已安装包需要重新构建后才包含修复。
